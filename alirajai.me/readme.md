# Ali Rajai Premium Portfolio Website

A static single page portfolio and service website for Ali Rajai. It uses a dark luxury visual style, smooth GSAP-powered motion, custom cursor effects, responsive layouts, and direct WhatsApp and email contact calls to action.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- GSAP and ScrollTrigger from CDN
- Static hosting on Netlify, GitHub Pages, Vercel, Cloudflare Pages, cPanel, or similar providers

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static file server. No build step is required.
